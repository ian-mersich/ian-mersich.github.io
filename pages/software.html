Resources / Software

Tools for exploring and communicating research

I build tools for scientific analysis and figure making. Superbench connects data, code, analysis, and visual work in one project. Figure Tool and the miRNA Predictor also have browser editions; the HSP90 Atlas helps researchers inspect published evidence about the HSP90 family.

01

Desktop software
In development

Superbench

Superbench keeps data, analyses, figures, and presentations in one saved project. Workbench brings together tools for preparing data, exploring measurements, working with scientific tables and R, and creating analyses. Figure and Present turn selected work into editable figures and slides.

Project / Documents lets researchers reopen their work; Artifact map and Activity show recorded relationships and steps. Tool Library brings analytical tools, analysis guides, and R/Bioconductor packages together. An open-source foundation for researcher-created tools and workflows is planned.

Browser edition available

miRNA Predictor

Estimate the abundance of 465 mature microRNAs from supported RNA-seq gene-expression tables. Review input coverage, inspect sample-level predictions and per-miRNA study comparisons, and download the results. Estimates support hypothesis generation and do not replace direct small-RNA measurements.

The standalone browser app runs on your device without sending expression files to an inference server. The same predictor is integrated into the current Superbench development app; inclusion in an installed Superbench release is still in preparation.
